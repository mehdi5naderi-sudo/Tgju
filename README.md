# TGJU — قیمت بازار

مجموعه‌ای از ابزارهای سبک و مستقل برای مشاهده‌ی شاخص‌های بازار؛ با رابط فارسی و تمرکز بر سرعت و خوانایی.

## نسخه‌های قابل استفاده

| ابزار | کاربرد | دسترسی |
|---|---|---|
| وب‌اپ | مشاهده‌ی قیمت‌ها در مرورگر و نصب به‌صورت PWA | [اجرای وب‌اپ](https://mehdi5naderi-sudo.github.io/Tgju/) |
| ویجت اندروید | نمایش شاخص‌های منتخب روی صفحه‌ی اصلی گوشی | [آخرین APK در Releases](https://github.com/mehdi5naderi-sudo/Tgju/releases/latest) |
| برنامه‌ی ویندوز | برنامه‌ی سبک Win32 با آیکون سینی سیستم؛ بدون نیاز به .NET | [آخرین نسخه در Releases](https://github.com/mehdi5naderi-sudo/Tgju/releases/latest) |
| ربات تلگرام | دریافت قیمت‌ها با دستور و دکمه‌ی بروزرسانی | [راهنمای ربات](telegram-bot/README.md) |

## امکانات

- نمایش شاخص‌های منتخب مانند تتر، دلار، گرم طلای ۱۸، سکه امامی، صندوق‌های طلا، انس، نفت برنت و بورس
- رابط فارسی و سازگار با موبایل و دسکتاپ
- نمایش قیمت، تغییرات و زمان داده در مواردی که منبع ارائه می‌کند
- بروزرسانی دستی؛ بدون ادعای تضمین قیمت لحظه‌ای
- نسخه‌های جداگانه برای وب، اندروید، ویندوز و تلگرام

## ساختار مخزن

| مسیر | محتوا |
|---|---|
| `index.html`، `manifest.json`، `sw.js`، `icon.svg` | وب‌اپ اصلی و فایل‌های PWA |
| `app/` | سورس فعال ویجت اندروید |
| `desktop-native/` | سورس برنامه‌ی ویندوز |
| `telegram-bot/` | ربات تلگرام و راهنمای استقرار |
| `.github/workflows/` | فرایندهای ساخت APK، برنامه‌ی ویندوز و انتشار GitHub Pages |
| `ajax/` | نسخه‌ی جایگزین/قدیمی وب‌اپ با مسیر داده‌ی جداگانه |
| `proxy/` | کد واسط API که برای نسخه‌ی جایگزین `ajax/` نگهداری شده است |

**نکته:** پوشه‌ی `ajax/` نسخه‌ی اصلی سایت نیست؛ نسخه‌ی اصلی در ریشه‌ی مخزن قرار دارد. پوشه‌های `ajax/` و `proxy/` فعلاً برای جلوگیری از شکستن مسیرهای قدیمی نگه داشته شده‌اند.

## توسعه

- برای تغییر وب‌اپ اصلی، فایل‌های ریشه را ویرایش کنید.
- برای ویجت اندروید، سورس داخل `app/` و گردش‌کار `build-apk.yml` را بررسی کنید.
- برای برنامه‌ی ویندوز، سورس داخل `desktop-native/` و گردش‌کار `build-tgju-native.yml` را بررسی کنید.
- برای ربات، راهنمای [telegram-bot/README.md](telegram-bot/README.md) را ببینید.
- خروجی ساخت‌ها و خطاها در [GitHub Actions](https://github.com/mehdi5naderi-sudo/Tgju/actions) و نسخه‌های قابل دریافت در [Releases](https://github.com/mehdi5naderi-sudo/Tgju/releases) قرار می‌گیرند.

## منبع داده

این پروژه از داده‌های وب‌سایت [TGJU](https://www.tgju.org/) استفاده می‌کند و وابستگی رسمی یا تأییدشده‌ای به آن وب‌سایت را ادعا نمی‌کند. تازگی و دسترس‌پذیری قیمت‌ها به سرویس منبع و اتصال شبکه بستگی دارد.

## سلب مسئولیت

این ابزارها برای نمایش اطلاعات بازار هستند و توصیه‌ی سرمایه‌گذاری یا تضمین قیمت لحظه‌ای محسوب نمی‌شوند. پیش از تصمیم مالی، داده‌ها را از منابع معتبر بررسی کنید.

## مجوز

در حال حاضر مجوز متن‌باز مشخصی برای این مخزن اعلام نشده است. پیش از بازاستفاده یا بازتوزیع کد، شرایط مالک پروژه را بررسی کنید.
