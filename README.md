# TGJU Market Dashboard

داشبورد سبک و واکنش‌گرا برای مشاهده‌ی سریع قیمت بازارها، با رابط کاربری فارسی و مناسب موبایل و دسکتاپ.

**نسخه‌ی آنلاین:** https://mehdi5naderi-sudo.github.io/Tgju/

## امکانات

- نمایش اطلاعات بازار در یک صفحه‌ی ساده و کم‌حجم
- پشتیبانی از شاخص‌هایی مانند تتر، دلار، طلای ۱۸ عیار، سکه امامی، صندوق‌های طلا، انس جهانی، نفت برنت و شاخص بورس
- رنگ‌بندی تغییرات قیمت برای تشخیص سریع وضعیت بازار
- نمایش زمان به‌روزرسانی اطلاعات
- به‌روزرسانی دستی با دکمه‌ی «بروزرسانی»؛ بدون رفرش خودکار صفحه
- طراحی واکنش‌گرا برای نمایشگرهای کوچک و بزرگ
- قابلیت اجرا به‌صورت وب‌اپ قابل نصب (PWA)، در مرورگرهای سازگار
- نسخه‌ی ویندوزی نیتیو در همین مخزن

## استفاده

برای استفاده از داشبورد، صفحه‌ی آنلاین را باز کنید:

**https://mehdi5naderi-sudo.github.io/Tgju/**

برای مشاهده‌ی آخرین اطلاعات، دکمه‌ی «بروزرسانی» را بزنید. در صورت در دسترس نبودن منبع داده، دریافت اطلاعات ممکن است با خطا مواجه شود.

## منبع داده

این پروژه اطلاعات بازار را از صفحات/داده‌های وب‌سایت [TGJU](https://www.tgju.org/) دریافت می‌کند. در دسترس بودن و تازگی اطلاعات به سرویس منبع و اتصال شبکه وابسته است. این پروژه وابستگی رسمی یا تأییدشده‌ای به TGJU را ادعا نمی‌کند.

## ساختار کلی

- فایل‌های ریشه‌ی مخزن: نسخه‌ی وب و فایل‌های مرتبط با اجرای آن
- فایل‌های مربوط به ویندوز: برنامه‌ی نیتیو و اجزای ساخت آن
- `.github/workflows/`: گردش‌کارهای خودکار GitHub Actions، در صورت پیکربندی

## توسعه و مشارکت

مخزن را Fork کنید، تغییرات را در یک شاخه‌ی جداگانه اعمال کنید و سپس Pull Request بفرستید. برای گزارش مشکل، می‌توانید از بخش Issues مخزن استفاده کنید.

## سلب مسئولیت

این پروژه صرفاً برای نمایش و بررسی اطلاعات است و توصیه‌ی سرمایه‌گذاری یا تضمین قیمت لحظه‌ای محسوب نمی‌شود. پیش از هر تصمیم مالی، اطلاعات را از منابع معتبر بررسی کنید.
