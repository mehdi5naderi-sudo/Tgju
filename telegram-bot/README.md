# ربات تلگرام قیمت‌های TGJU

این ربات با هر درخواست، قیمت‌ها را از API مورد استفادهٔ وب‌اپ TGJU دریافت می‌کند و آن‌ها را به‌صورت پیام متنی با نشانه‌های رنگی نمایش می‌دهد. تلگرام رنگ فونت دلخواه برای هر خط را پشتیبانی نمی‌کند؛ بنابراین از 🟢 افزایش، 🔴 کاهش و 🟡 خنثی استفاده می‌شود.

## امکانات

- دستورهای `/start` و `/price`
- دکمهٔ درون پیام برای دریافت دوبارهٔ قیمت‌ها
- دریافت تازه از API: `https://api.tgju.org/v1/widget/tmp`
- موارد: تتر، دلار، گرم ۱۸، امامی، کهربا، عیار، انس، نفت برنت و شاخص بورس
- بدون نیاز به اجرای دائمی فرایند؛ با webhook روی Vercel اجرا می‌شود.

## راه‌اندازی

1. در تلگرام به **@BotFather** بروید و با دستور `/newbot` یک ربات بسازید. توکن را در چت یا در کد قرار ندهید.
2. این پوشه را به‌عنوان **Root Directory** یک پروژهٔ جدید در Vercel انتخاب کنید و آن را Deploy کنید.
3. در تنظیمات Environment Variables پروژه، این متغیرها را اضافه کنید:
   - `TGJU_BOT_TOKEN`: توکن دریافتی از BotFather
   - `TGJU_WEBHOOK_SECRET`: یک رشتهٔ تصادفی و محرمانه، فقط از حروف انگلیسی و عدد، بین ۲۰ تا ۶۰ نویسه
4. پس از Deploy، آدرس webhook برابر است با:
   `https://YOUR-PROJECT.vercel.app/api/webhook`
5. در مرورگر این نشانی را باز کنید و مقادیر جایگزین‌شده را وارد کنید:
   `https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook?url=https%3A%2F%2FYOUR-PROJECT.vercel.app%2Fapi%2Fwebhook&secret_token=YOUR_WEBHOOK_SECRET`
   **این نشانی شامل توکن ربات است؛ آن را برای کسی نفرستید و در جایی عمومی منتشر نکنید.** پاسخ باید شامل `"ok":true` باشد.
6. در تلگرام `/start` یا `/price` را برای ربات بفرستید.

اگر توکن قبلاً جایی عمومی منتشر شده، از BotFather آن را عوض کنید. ربات فقط قیمت‌های در دسترس API را نشان می‌دهد؛ اگر ساختار یا دسترسی API تغییر کند، باید کد به‌روزرسانی شود.
